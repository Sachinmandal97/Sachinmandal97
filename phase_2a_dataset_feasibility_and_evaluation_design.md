## 2. Verified Dataset Facts and Academic Sources

### 2.1 Candidate Dataset 1: NewsCLIPpings

* **Official Publication:**  
  Luo, G., Darrell, T., & Rohrbach, A. (2021). *"NewsCLIPpings: Automatic Generation of Out-of-Context Multimodal Media."* Proceedings of the 2021 Conference on Empirical Methods in Natural Language Processing (EMNLP 2021), pages 6801–6817. [ACL Anthology: 2021.emnlp-main.545].
* **Official Repository:** [`https://github.com/g-luo/news_clippings`](https://github.com/g-luo/news_clippings)
* **Underlying Source Data:** Sourced from the *VisualNews* dataset (comprising news articles and imagery from *BBC*, *The Guardian*, *USA Today*, and *Reuters*).
* **Task Definition:**  
  Evaluates detection of **out-of-context (OOC) multimodal media (*cheapfakes*)**. The text caption is an authentic news caption, and the image is an authentic news photograph, but they are mismatched to produce a deceptive narrative.
* **Ground-Truth Label Space:**  
  Binary classification:
  - `pristine` (0): The original, authentic image-caption pairing from the news publisher.
  - `falsified` (1): An artificially mismatched pairing generated by automated retrieval strategies.
* **Generative Threat Splits:**  
  The dataset provides balanced (50% pristine, 50% falsified) splits reflecting different adversarial mismatch strategies:
  1. `random`: Captions paired with random images.
  2. `semantics_clip_text_text`: Mismatched images selected via CLIP text-text embedding proximity.
  3. `semantics_clip_image_image`: Mismatched images selected via CLIP image-image embedding proximity.
  4. `person_sbert_text_text`: Mismatched captions constrained to share named person entities (`[PERSON]`).
  5. `scene_resnet_place`: Mismatched imagery sharing background scene semantics via Places-ResNet50.
* **Input Fields & Modalities:**  
  - Modalities: Image ($I$) and Caption Text ($T$).
  - Required Fields: `id`, `image_id` / `image_path`, `caption`, `falsified`.
  - Reference Evidence: **None.** NewsCLIPpings does not supply external reference documents or fact-checking articles.

### 2.2 Candidate Dataset 2: Factify 2

* **Official Publication & Workshop:**  
  Mishra, S., et al. (2023). *"Factify 2: A Multimodal Fact Verification Dataset."* Released as part of the *De-Factify 2* Workshop at the 37th AAAI Conference on Artificial Intelligence (AAAI-23). Published in CEUR Workshop Proceedings.
* **Official Repository & Portal:**  
  - GitHub: [`https://github.com/surya1701/Factify-2.0`](https://github.com/surya1701/Factify-2.0)
  - Portal: [`https://aiisc.ai/defactify2/factify.html`](https://aiisc.ai/defactify2/factify.html)
* **Task Definition:**  
  Multimodal fact verification. Compares social media claims against verified reference documents across both text and visual modalities to classify the truth-conditional relationship.
* **Ground-Truth Label Space (5 Fine-Grained Classes):**
  1. `Support_Multimodal`: The claim is corroborated by both the text and the visual content of the reference document.
  2. `Support_Text`: The claim is corroborated primarily by the textual content of the reference document.
  3. `Refute`: The claim is directly contradicted by the reference document (proven false).
  4. `Neutral`: The reference document mentions related context but neither supports nor refutes the claim.
  5. `Insufficient_Multimodal`: The reference document lacks sufficient evidence across modalities to verify or refute the claim.
* **Input Fields & Modalities:**  
  - Modalities: Multimodal Claim $(T_{\text{claim}}, I_{\text{claim}})$ paired with Multimodal Document $(T_{\text{doc}}, I_{\text{doc}})$.
  - Required Fields: `sample_id`, `claim_text`, `claim_image`, `document_text`, `document_image`, `category` (or `label`).
  - Optional Fields: `claim_ocr`, `document_ocr`.
  - Reference Evidence: **Supplied directly.** Each sample includes a paired reference document.

## 5. Definition of Three Distinct Evaluation Tasks

To avoid conflating fundamentally different ML tasks into an uninterpretable single metric, the evaluation protocol establishes **three separate evaluation experiments**:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        THREE DISTINCT BENCHMARK EVALUATION TASKS                       │
├──────────────────────────────┬─────────────────────────────┬───────────────────────────┤
│ TASK A: Visual-Semantic      │ TASK B: Evidence-Grounded   │ TASK C: Unified Multimodal│
│ Cheapfake Detection          │ Factual Claim Verification  │ Fact Verification         │
├──────────────────────────────┼─────────────────────────────┼───────────────────────────┤
│ • Dataset: NewsCLIPpings     │ • Dataset: Factify 2 (Text) │ • Dataset: Factify 2 (MM) │
│ • Target: pristine vs.       │ • Target: Entailment vs.    │ • Target: 5-Class /       │
│   falsified                  │   Contradiction vs. Neutral │   3-Class Epistemic State │
│ • Evaluates: OpenCLIP branch │ • Evaluates: spaCy + DeBERTa│ • Evaluates: Full Pipeline│
│ • External Docs: None        │ • External Docs: Paired Doc │ • External Docs: Paired MM│
└──────────────────────────────┴─────────────────────────────┴───────────────────────────┘
```

### 5.1 Task A: Visual-Semantic Cheapfake Detection (Out-of-Context Image Detection)
* **Research Question:** **RQ2** — Can zero-shot vision-language alignment ($s_{TI} = \hat{h}_T^\top \hat{h}_I$) reliably separate original news image-caption pairs from adversarially mismatched pairs?
* **Input Fields:** Image $I$, Caption Text $T$.
* **Ground-Truth Target:** Binary label $Y_A \in \{\text{pristine}, \text{falsified}\}$.
* **Model Output Evaluated:** OpenCLIP cosine similarity $s_{TI} \in [-1.0, 1.0]$ and binary indicator $m_{TI} = \mathbb{I}(s_{TI} < \tau_{\text{cm}})$.
* **Valid Label Mapping:**
  $$\hat{Y}_A = \begin{cases} \text{pristine} & \text{if } s_{TI} \ge \tau_{\text{cm}} \quad (m_{TI} = 0) \\ \text{falsified} & \text{if } s_{TI} < \tau_{\text{cm}} \quad (m_{TI} = 1) \end{cases}$$
  Default threshold: $\tau_{\text{cm}} = 0.22$.
* **Metrics:**
  - Binary Accuracy, Balanced Accuracy.
  - Precision, Recall, and F1 on the minority/adversarial class (`falsified`).
  - Macro-F1 across `pristine` and `falsified`.
  - Area Under ROC Curve (ROC-AUC) and Precision-Recall Curve (PR-AUC) using continuous distance $(1.0 - s_{TI})$.
* **Known Limitations:** Evaluates image-text semantic correlation only. Cannot determine whether the text caption itself is factually true or false in the real world.

### 5.2 Task B: Evidence-Grounded Factual Claim Verification (Textual Branch)
* **Research Question:** **RQ1 & RQ4** — How accurately does the DeBERTa-v3 cross-encoder, coupled with atomic claim decomposition, predict entailment, contradiction, and neutrality against paired reference documents?
* **Input Fields:** Claim Text $T$, Paired Reference Document Text $D$.
* **Ground-Truth Target:** 3-Class truth relation $Y_B \in \{\text{SUPPORTED}, \text{MISLEADING}, \text{UNCERTAIN}\}$.
* **Derived Factify 2 Mapping:**
  - `Support_Text` $\cup$ `Support_Multimodal` $\implies \text{SUPPORTED}$
  - `Refute` $\implies \text{MISLEADING}$
  - `Neutral` $\cup$ `Insufficient_Multimodal` $\implies \text{UNCERTAIN}$
* **Model Output Evaluated:** Proposition status aggregation $\hat{Y}_B = \mathcal{F}_{\text{text}}(\{\sigma(t_j)\}_{j=1}^k)$.
* **Metrics:**
  - Macro-F1 across the 3 classes.
  - Per-class Precision, Recall, and F1 for `SUPPORTED`, `MISLEADING`, and `UNCERTAIN`.
  - Confusion Matrix (normalized).
* **Known Limitations:** Ignores visual assets in both claim and document. Evaluates NLI verification conditioned on reference documents, bypassing web retrieval recall.

### 5.3 Task C: Unified Multimodal Misinformation Assessment (End-to-End)
* **Research Question:** **RQ1, RQ2, RQ3, RQ4, RQ5** — How effectively does the integrated framework (fusing proposition decomposition, DeBERTa NLI, OpenCLIP alignment, and epistemic uncertainty) adjudicate complex multimodal claims?
* **Input Fields:** Multimodal Claim $(T_{\text{claim}}, I_{\text{claim}})$ + Multimodal Document $(T_{\text{doc}}, I_{\text{doc}})$.
* **Evaluation Protocols:**
  - **Protocol C1 (Official 5-Class Evaluation):** Requires mapping pipeline verdicts to Factify 2's 5 native classes:
    - $\text{SUPPORTED} \land m_{TI} = 0 \implies \text{Support\_Multimodal}$
    - $\text{PARTIALLY\_SUPPORTED} \lor (\text{SUPPORTED} \land m_{TI} = 1) \implies \text{Support\_Text}$
    - $\text{MISLEADING} \implies \text{Refute}$
    - $\text{UNCERTAIN} \land r_{\text{rel}} \ge \tau_{\text{rel}} \implies \text{Neutral}$
    - $\text{UNCERTAIN} \land r_{\text{rel}} < \tau_{\text{rel}} \implies \text{Insufficient\_Multimodal}$
  - **Protocol C2 (3-Class Epistemic Evaluation - Recommended Primary):** Evaluates the core epistemic states by collapsing Factify 2 labels as in Task B.
* **Metrics:**
  - Macro-F1, Per-class F1, Multi-class Confusion Matrix.
  - Selective Classification Accuracy: Accuracy as a function of coverage when abstaining on samples where uncertainty $u \ge \tau_u$.

## 7. Baselines and Systematic Ablation Suite

To validate the empirical necessity of each pipeline stage, the evaluation design specifies 5 comparative baselines and 4 ablation configurations.

### 7.1 Baseline Comparisons
1. **Majority Class / Random Baseline:** Naive control representing zero-information performance.
2. **Vision-Only Alignment Baseline (CLIP-Alone):** Evaluates claims based purely on OpenCLIP cosine similarity $s_{TI}$, with no evidence retrieval or NLI. (Direct baseline for Task A).
3. **Text-Only Evidence Verification Baseline (DeBERTa-Alone):** Evaluates claims based purely on text NLI against reference documents, bypassing all visual inputs ($I = \emptyset$). (Direct baseline for Task B).
4. **Standard Supervised Multimodal Baseline (Literature):** Reference performance from published literature (e.g. Luo et al. baseline on NewsCLIPpings, Mishra et al. baseline on Factify 2).
5. **Full Proposed Modular Framework:** Complete integrated pipeline with atomic decomposition, relevance filtering, DeBERTa NLI, OpenCLIP alignment, and multi-branch decision fusion.

Table 7.1 details the 4 systematic ablations that can be executed directly in the existing codebase:

### Table 7.1: Systematic Component Ablation Matrix

| Ablation Configuration | Parameter / Code Mechanism | RQ Evaluated | Expected Empirical Impact |
| :--- | :--- | :---: | :--- |

## 8. Sampling Strategy, Statistical Confidence, and Leakage Prevention

### 8.1 Sampling Feasibility & Computational Budget

* **Local CPU Runtime Reality:**  
  Phase P0.1 live smoke tests demonstrated an average CPU execution latency of **$7.5\text{--}15.0$ seconds per sample** when running OpenCLIP ViT-B/32, spaCy dependency parsing, and DeBERTa-v3 cross-encoder inference sequentially on Windows CPU.
* **Batch Computational Budget Table:**
  - $N = 50$ samples $\implies \approx 6.2\text{--}12.5$ minutes.
  - $N = 100$ samples $\implies \approx 12.5\text{--}25.0$ minutes.
  - $N = 200$ samples $\implies \approx 25.0\text{--}50.0$ minutes.
  - $N = 10,000$ samples (Full Dataset) $\implies \approx 21.0\text{--}41.6$ **hours** (Prohibitive on CPU).
* **Feasibility Finding:**  
  Evaluating a stratified subset of **$N = 100\text{--}200$ samples** is computationally feasible on the local CPU workstation, whereas running full 50,000-sample benchmark splits without GPU acceleration is impractical.

### 8.2 Statistical Defensibility & Sample Size Rigor

> [!IMPORTANT]
> **Academic Justification of Sample Size $N = 200$:**  
> A sample size of $N = 200$ cannot be claimed to be "infinitely representative of the full global population". However, it is **statistically defensible as an academic evaluation sample** if accompanied by formal confidence intervals.  
> For a sample size of $N = 200$, the maximum standard error of a proportion is:
> $$\text{SE} = \sqrt{\frac{p(1-p)}{N}} \le \sqrt{\frac{0.5 \times 0.5}{200}} \approx 0.0354$$
> The resulting 95% margin of error is $E = 1.96 \times \text{SE} \approx \pm 6.93\%$.  
> All reported metrics in the dissertation must be reported with **95% Wilson score confidence intervals** (e.g., $\text{Macro-F1} = 74.2\% \pm 6.1\%$) rather than bare point estimates.

### 8.3 Stratified Sampling Protocol

To maximize statistical validity, sampling must not be uniform random. It must follow a strict **stratified sampling protocol**:
1. **NewsCLIPpings ($N = 200$ Test Samples):**
   - Exactly 100 `pristine` samples.
   - Exactly 100 `falsified` samples, stratified across threat types: 20 `random`, 20 `semantics_clip_text_text`, 20 `semantics_clip_image_image`, 20 `person_sbert_text_text`, 20 `scene_resnet_place`.
2. **Factify 2 ($N = 200$ Validation Samples):**
   - Exactly 40 samples from each of the 5 classes:
     - 40 `Support_Multimodal`
     - 40 `Support_Text`
     - 40 `Refute`
     - 40 `Neutral`
     - 40 `Insufficient_Multimodal`

### 8.4 Data Leakage Prevention Protocol

To guarantee academic reproducibility and eliminate data leakage:
1. **Split Isolation:** Samples must be drawn exclusively from the official `val` or `test` splits. Zero training set samples may enter the evaluation harness.
2. **Retriever Index Cleanliness:** The local BM25 index must not index benchmark test documents or test-set ground-truth text.
3. **Cache Flushing:** The `EvidenceRetriever` query cache must be explicitly purged before every benchmark evaluation run:
   ```python
   pipeline.retriever.clear_cache()
   ```
4. **No Test-Set Threshold Tuning:** Cutoff thresholds ($\tau_{\text{cm}} = 0.22, \tau_{\text{ent}} = 0.60, \tau_{\text{contra}} = 0.50, \tau_{\text{rel}} = 0.20$) must remain fixed at their predefined default values. Under no circumstances may thresholds be swept or optimized on the test split.
5. **Deterministic Seeding:** All data samplers must use `seed: 42` to guarantee exact bit-for-bit repeatability across independent runs.

## 10. Formal Go / No-Go Recommendations

### 1. NewsCLIPpings (Task A — Cheapfake Detection)
* **Recommendation:** **GO (Conditional on Embeddings or Sub-Sample Images).**
* **Justification:** NewsCLIPpings is the gold standard for evaluating out-of-context news imagery (RQ2). The OpenCLIP ViT-B/32 architecture in `src/cross_modal.py` is a 100% direct match for this dataset. Because downloading the full 100GB VisualNews dataset is impractical, the evaluation should utilize either the precomputed CLIP embeddings or a curated stratified subset of 100–200 validated image-caption pairs.

### 2. Factify 2 (Task B & Task C — Evidence-Grounded Fact Verification)
* **Recommendation:** **GO.**
* **Justification:** Factify 2 is the most appropriate benchmark for evaluating the full multi-stage pipeline (RQ1, RQ3, RQ4, RQ5). It provides paired claims and reference documents, covering multi-modal support, text support, refutation, and evidence insufficiency. The loader schema and label normalizer are already implemented and verified in `src/data_loader.py`. Evaluating Factify 2 under both 3-class epistemic collapse (Task B) and 5-class multimodal adjudication (Task C) provides an academically rigorous dissertation evaluation.

### 3. MMFakeBench (Generalization Benchmark)
* **Recommendation:** **NO-GO (Hold for Phase 3 / Future Work).**
* **Justification:** MMFakeBench introduces multiple disparate manipulation formats and lacks an existing ingestion adapter in the codebase. Committing to a third benchmark risks diluting focus and exhausting local computational budgets. Evaluating NewsCLIPpings and Factify 2 thoroughly is fully sufficient for an MSc Data Science dissertation.
