## 3. Data Flow Traceability

To assist with academic defense and code auditing, Table 3.1 traces the exact lifecycle of a sample through the application:

### Table 3.1: Data Flow Pipeline Traceability

| Step | Operation | Input Object | Output Object | Key Transformation & Safeguards |
| :---: | :--- | :--- | :--- | :--- |
| **1** | User Input & Preset State | Streamlit UI (`app.py`) | `MultimodalSample` | Decouples presets from custom claims. If text modified or custom mode selected, `image_path` set to `None` unless uploaded. |
| **2** | Text Preprocessing | `sample.claim_text` | `clean_claim: str` | Strips typographic artifacts, curly quotes, Unicode anomalies via `clean_text()`. |
| **3** | Image Loading & Validation | `sample.image_path` | `(image_obj, err)` | Validates image file via PIL; converts to RGB. Returns `(None, error)` gracefully if missing or corrupt. |
| **4** | OCR Extraction | `image_obj` | `OCRResult` | Evaluates EasyOCR. When uninstalled, returns `has_text=False` without crash or hallucination. |
| **5** | Vision-Language Alignment | `image_obj`, `clean_claim` | `CrossModalScore` | OpenCLIP dual-encoder computes cosine similarity. If `image_obj is None`, returns bypass score $0.50$ with `mismatch_detected=False`. Tokenizes full string with `truncation=True, max_length=77`. |
| **6** | Claim Decomposition | `clean_claim` | `List[AtomicClaim]` | spaCy parses sentences and regex splits sub-clauses, extracting entities, dates, and locations. |
| **7** | Evidence Retrieval | `List[AtomicClaim]` | `List[EvidenceSnippet]` | Queries Google News RSS, Wikipedia, and local BM25. Caches queries with TTL. Enforces entity-anchor relevance filtering ($\ge 0.20$). Rejects root publisher homepages. |
| **8** | Claim-Evidence NLI | `AtomicClaim`, `EvidenceSnippet` | `List[AtomicVerificationResult]` | DeBERTa-v3 evaluates directional relation (`[CLS] Evidence [SEP] Claim [SEP]`). Assigns per-proposition status. |
| **9** | Decision Fusion | `CrossModalScore`, `AtomicResults` | `(DecisionVerdict, reasons)` | Rule-based aggregation enforces contradiction precedence, handles partial corroboration, and flags visual mismatches. |
| **10** | Uncertainty Calculation | Verdict, Margins | `(confidence, uncertainty)` | Blends NLI probability margin and CLIP cutoff margin into normalized $[0, 1]$ indices. |
| **11** | Explanation Synthesis | All intermediate signals | `structured_explanation: str` | Formats comprehensive audit report citing exact evidence IDs, source URLs, and component scores. |
